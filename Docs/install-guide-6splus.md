# TextRelay 手机安装指南（iPhone 6s Plus · iOS 15.8 · Dopamine 越狱）

> 面向最终用户的分步教程。目标：让手机自动把短信/通知转发到 Bark、钉钉、企业微信、飞书、邮件等 18 种服务之一。

## 0. 前提检查

- [ ] 手机已越狱且当前处于**已注入状态**（Dopamine App 里点过 Jailbreak，Sileo 能正常打开）
- [ ] Sileo 包管理器已安装（Dopamine 越狱后自带）
- [ ] 知道自己要把短信转发到哪个服务（本指南以 **Bark** 为例，其他服务字段含义见设置页内说明）

## 1. 添加软件源

1. 手机打开 **Sileo → 底部「软件源」标签**
2. 右上角 **「+」→ 输入源地址**：
   ```
   https://hlakbrr.github.io/TextRelay/
   ```
3. 等待源刷新，添加成功后源列表出现「hlakbrr」

## 2. 安装依赖与主程序

1. 先确保已添加 **opa334 官方源**：`https://opa334.github.io/`（Dopamine 越狱后 Sileo 通常已内置）
2. Sileo → 搜索 `TextRelay`
3. 右上角「获取」，依赖会自动一并安装（AltList、libSandyXpc、SandyXpc 运行时等）
4. 安装完成后按提示 **注销（respring）**

## 3. 配置转发服务（以 Bark 为例）

1. App Store 安装 **Bark**（免费的 iOS 推送 App）
2. 打开 Bark，复制首页测试 URL 里的 key（形如 `https://api.day.app/xxxxxxxx/推送内容` 中那串 `xxxxxxxx`）
3. 手机 **设置 → TextRelay**：
   - 总开关打开（Enabled）
   - 点「服务」→ 右上角「+」→ 选 **Bark**
   - 粘贴 key，点右上角「测试」→ Bark 收到推送即配置成功
4. 如果你想转发到 **钉钉/企业微信/飞书**：服务列表里选对应项，按设置页里的说明填机器人 Token/Webhook 即可（每个设置页都有中文说明）

## 4. 开启短信转发

1. 设置 → TextRelay → **「收信」**（SMS subscription）打开
2. **保持「信息」App 的系统通知权限开启**（设置 → 通知 → 信息 → 允许通知）。短信转发的实现依赖系统通知，通知被系统完全关闭时收不到
3. 双卡用户：设置里可为每个卡槽命名，转发消息会带卡槽名

## 5. 过滤规则（只转发验证码等）

1. 设置 → TextRelay → 规则/过滤相关设置
2. 用关键词或正则匹配（如 `\d{4,}` 匹配带数字验证码），避免所有短信都推到手机
3. **防循环**：如果你在本机也装了 Bark 且开启本机通知转发，务必把 Bark 加入 **App 黑名单**，否则 Bark 收到推送 → 产生通知 → 又被转发 → 无限循环

## 6. 验证

让朋友给你发条短信，或用另一台手机发一条，看 Bark/钉钉是否收到。没收到时按下面排查。

## 常见问题

**Q: 设置里没有 TextRelay 面板？**
说明 tweak 没有注入。确认：Sileo 里 TextRelay 已安装 → Dopamine App 内重新点 Jailbreak 注入 → 注销。Dopamine 越狱是半不完美越狱，**每次重启手机后都要重新越狱**，否则插件不加载。

**Q: 短信不转发，但 App 通知正常？**
检查「收信」开关是否开启；信息 App 通知权限是否开启；部分系统版本下需要等 imagent 重启（注销即可）。

**Q: 验证码短信被系统自动清理？**
iOS 会自动删除验证码短信（设置 → 信息 → 保留信息），删除前收到过就会转发，不影响。

**Q: 推送服务收到的是乱码？**
在服务设置里检查编码设置，中文短信默认 UTF-8；Bark 服务端会正常显示中文。

**Q: 推到钉钉/飞书被限流？**
插件默认重试 5 次，遇到限流可稍后重试或换 webhook 类型服务。

**FAQ 更多问题看上游文档**：上游 Pusher 的 Docs/ 目录有更详细的各服务配置文档（中文），TextRelay 保留了这个 Docs/ 目录。

## 卸载

Sileo → 已安装 → TextRelay → 卸载 → 注销。
